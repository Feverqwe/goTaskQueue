# GoTaskQueue

- Использовать инструменты GoTaskQueue MCP для всех операций с запущенным task runner.
- Если MCP недоступен, сообщить об этом и не заменять удаленную операцию локальным shell.

## Выбор и запуск

1. Найти подходящий шаблон через `templates_search`; предпочитать специализированный шаблон интерактивному shell.
2. Разрешить точный ID или place через `template_get`; не угадывать идентификаторы.
3. Проверить описание, побочные эффекты, обязательные переменные и допустимые значения.
4. Запускать через `task_start` только после явной просьбы пользователя. Сообщить созданный task ID.
5. Для точного повторения существующей задачи использовать `task_rerun`; не повторять упавшую задачу автоматически.

## Наблюдение за задачей

- Использовать `task_output` для немедленного чтения и `task_follow` для ограниченного ожидания.
- Передавать `next_cursor` в следующий вызов и учитывать `truncated`.
- Продолжать ожидание, если пользователь ожидает результат длительной задачи; не считать отсутствие нового вывода завершением.
- При завершении сообщить состояние и существенную часть вывода. При ошибке также сообщить поле error и последние релевантные строки.

## Работа с PTY

1. Сначала прочитать текущие `output` и `screen`, затем отправлять ввод.
2. Через `task_input` отправлять одну команду или один ответ на prompt за раз; после каждого ввода снова читать задачу.
3. Сохранять один PTY-task, когда важны `cd`, переменные окружения или состояние интерактивного процесса.
4. При необходимости изменить геометрию через `task_resize`.
5. Для прерывания foreground-команды сначала отправить `CTRL_C`. Использовать `task_stop`, только если требуется остановить всю задачу.
6. Завершать shell командой `exit` и убедиться через `task_follow`, что задача завершилась.

## Изменения и удаление

- Не отправлять ввод, не останавливать и не перезапускать задачу без соответствующего намерения пользователя.
- Выполнять обычные необходимые команды без подтверждения каждой команды, если пользователь явно поручил работу; отдельно согласовывать необратимые или существенно более широкие действия.
- Перед `task_delete` получить явное подтверждение: операция необратимо удаляет задачу и ее сохраненные логи.
